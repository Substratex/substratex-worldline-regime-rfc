# WRS RFC Process

Statuses: `Draft → Review → Candidate → Accepted → Superseded | Withdrawn`.

A scientific-semantics RFC should not reach Candidate solely from schema validation. Candidate evidence should include canonical pass/fail fixtures, negative and missingness cases, prospective temporal-leakage tests where relevant, versioned classification contracts, and independent implementation evidence.

Changes to canonical regime names, Worldline definition, temporal-marker meanings, lead-time admissibility, continuity semantics, or recovery semantics are normative changes.
