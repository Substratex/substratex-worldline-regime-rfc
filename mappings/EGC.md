# WRS ↔ Evidence-Governed Computation (EGC)

WRS defines what Worldline, regime, transition, marker, continuity, recovery, and lead-time objects mean.

EGC governs whether a claim about those objects is admissible for a declared evidence set, scope, surface, audience, and output.

Example: WRS may define `t_star` as confirmed while `t_f` is not supplied. EGC should therefore refuse a formal lead-time claim that requires both markers.
