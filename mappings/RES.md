# WRS ↔ Runtime Evidence Standard (RES)

WRS defines Worldline/regime measurement semantics. RES defines evidence formation, identity, lineage, lifecycle, challenge, issuance, export, and preservation.

A WRS object intended as governed Runtime Evidence should resolve to RES run/evidence identity, source relationship, method/version, support class, missingness, scope, lineage, and challenge state.

WRS does not create source facts or replace RES lifecycle semantics.
