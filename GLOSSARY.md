# Glossary

**Worldline** — Evidence-bound longitudinal representation of observable computational behavior over a declared runtime horizon.

**Regime** — Bounded state classification assigned to an interval of a Worldline under a declared classification contract.

**Transition** — Declared change between regime states.

**Temporal Marker** — Typed coordinate identifying an evidence-qualified event or transition reference.

**t_aw** — First qualified weakening.

**t_candidate** — Candidate boundary marker.

**t_star** — Confirmed boundary / Basin Exit marker.

**t_f** — Qualified observable failure marker.

**Lead-Time (Δt)** — `t_f - t_star`, computable only when both markers qualify under compatible coordinates.

**Open Watch** — Warning interval that remains open when a required failure marker is unavailable.

**Continuity** — Evidence-supported preservation of a trackable trajectory across a declared horizon.

**Recovery** — Canonical regime representing evidence-supported reformation after severe instability or collapse.

**Re-entry** — Bounded finding describing return to a previously occupied or structurally corresponding regime/basin under declared criteria.

**Brittle** — Secondary condition indicating low resilience. It is not a top-level WRS 1.0 regime.
