# RFC-WR-0013 — JSON Interchange Profile

**Status:** Draft  
**Target:** WRS 1.0  
**Namespace:** `urn:substratex:worldline-regime:1.0:`  
**Originator:** Arjay Asadi  
**Publisher:** SubstrateX®


WRS 1.0 uses JSON Schema 2020-12 for normative interchange schemas.

Coordinate objects identify coordinate system, value, unit/label where applicable, and ordering semantics.

Unavailable scientific objects use explicit missingness/status rather than invented numeric sentinels.

Unknown extension fields MUST NOT be treated as normative WRS semantics.
