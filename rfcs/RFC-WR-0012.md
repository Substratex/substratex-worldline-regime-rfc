# RFC-WR-0012 — Conformance Profiles and Test Requirements

**Status:** Draft  
**Target:** WRS 1.0  
**Namespace:** `urn:substratex:worldline-regime:1.0:`  
**Originator:** Arjay Asadi  
**Publisher:** SubstrateX®


WRS profiles:

- `WRS-Object`
- `WRS-Regime`
- `WRS-Transition`
- `WRS-Temporal`
- `WRS-Continuity`
- `WRS-LeadTime`
- `WRS-Recovery`
- `WRS-Full`

Minimum test families include canonical-regime enforcement, brittle-not-regime, candidate/confirmed separation, persistence and hysteresis rules, marker missingness, `t_star`/`t_f` independence, lead-time computability, open-watch behavior, prospective leakage, run-boundary continuity, recovery persistence, re-entry criteria, and explicit claim boundaries.

Conformance is not scientific validation or SubstrateX certification.
