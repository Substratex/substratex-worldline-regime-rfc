# RFC-WR-0001 — Worldline and Regime Architecture

**Status:** Draft  
**Target:** WRS 1.0  
**Namespace:** `urn:substratex:worldline-regime:1.0:`  
**Originator:** Arjay Asadi  
**Publisher:** SubstrateX®


## Governing model

`Longitudinal Computational Behavior → Worldline → Regime Intervals → Transitions → Temporal Markers → Bounded Findings`

A Worldline is the evidence-bound longitudinal representation of observable computational behavior over a declared runtime horizon.

## Invariants

1. temporal ordering;
2. run identity;
3. evidence binding;
4. explicit regime intervals;
5. candidate/confirmed distinction;
6. typed temporal markers;
7. missingness preservation;
8. no hidden-state inflation;
9. no causal inflation;
10. no prospective temporal leakage;
11. run-boundary honesty;
12. instrument independence.
