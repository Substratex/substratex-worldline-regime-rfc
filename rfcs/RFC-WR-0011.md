# RFC-WR-0011 — RES / WRS Interface

**Status:** Draft  
**Target:** WRS 1.0  
**Namespace:** `urn:substratex:worldline-regime:1.0:`  
**Originator:** Arjay Asadi  
**Publisher:** SubstrateX®


WRS defines scientific/measurement semantics. RES defines how evidence identity, source relationship, support class, missingness, scope, lineage, challenge state, issuance, export, and preservation are formed and carried.

WRS objects do not create source facts. Regime labels, transitions, markers, and findings are evidence-linked derived objects whose authority depends on declared methods and evidence.

WRS may be used independently for exploratory research, but an object MUST NOT be represented as RES-conformant unless RES requirements are separately satisfied.
