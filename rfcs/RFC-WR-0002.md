# RFC-WR-0002 — Worldline Object

**Status:** Draft  
**Target:** WRS 1.0  
**Namespace:** `urn:substratex:worldline-regime:1.0:`  
**Originator:** Arjay Asadi  
**Publisher:** SubstrateX®


A conformant Worldline SHALL identify worldline ID, run ID, coordinate system, ordered evidence horizon, evidence references, method/version, regime intervals, transition references, marker references, scope, and missingness.

A new run is a new Worldline by default. Cross-run reconstruction must explicitly identify all source runs and the reconstruction rule.

A Worldline MUST NOT be represented as direct access to hidden state, memory, consciousness, intent, personality, or causal mechanism.
